# What the UK Owes to Yemen: Boox mind map

A monochrome mind map of *Politics Theory Other*: “What the UK owes to Yemen w/ David Wearing” (1 Oct 2026).
It is built for the Boox Note Max (13.3", 4:3, E Ink).

| File | Use on the Boox |
|---|---|
| `what-the-uk-owes-to-yemen.pdf` | **Notes → Import → local file.** Vector, 9 pages: page 1 is the whole map (pinch to zoom), pages 2–9 are the eight branches at reading size. Annotate on top. |
| `what-the-uk-owes-to-yemen.png` | **Infinite note → Insert → Image.** 10800×8100 greyscale. Scale it on the canvas and write around it. |

The map has eight branches around a central medallion. Each branch has its own Boox-style shape (hexagon, framed rectangle, ellipse, parallelogram, octagon, inverted rounded rectangle, rhombus, pennant), line (solid, double, dotted, dashed, heavy, tapered brush, dash-dot, long-dash), leaf marker and box style. Four kinds of note are used: observation, key term, figure and quotation.

The content comes from a machine transcript of the episode audio (Whisper `small.en`). Figures were checked against the CAAT/TSP report *Reparations for Yemen* (Sept 2026).

Rebuild: `pip install playwright pillow pypdf && python3 build.py` (edit `content.json` to change the text).
